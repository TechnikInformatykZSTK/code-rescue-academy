# Informacja o danych i prywatności

**CODE RESCUE Academy – wersja bez kont i bez zapisu wyników na serwerze.**

- Kurs nie wymaga rejestracji ani podawania imienia, nazwiska czy adresu e-mail.
- Postępy i kod wpisywany w ćwiczeniach są przechowywane lokalnie w przeglądarce użytkownika za pomocą `localStorage`.
- Autor kursu i nauczyciel nie mają dostępu do tych lokalnych wyników przez GitHub Pages.
- Dane lokalne mogą zniknąć po wyczyszczeniu pamięci przeglądarki, zmianie urządzenia lub użyciu trybu prywatnego.
- Serwis GitHub Pages, jako dostawca hostingu, może przetwarzać techniczne dane związane z odwiedzinami (np. adres IP i logi). Obowiązują również zasady prywatności GitHub.
- Nie należy umieszczać w repozytorium danych osobowych uczniów, list klas, wyników sprawdzianów ani danych logowania.
- Wersja kursu nie jest przeznaczona do formalnego oceniania ani centralnego gromadzenia wyników.

Przed wdrożeniem kont uczniowskich, centralnego zapisu postępów lub ocen należy oddzielnie zaprojektować zabezpieczenia, role, retencję danych i podstawę prawną przetwarzania, zgodnie z zasadami obowiązującymi w szkole.
