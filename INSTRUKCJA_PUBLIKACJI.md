# Instrukcja publikacji CODE RESCUE Academy

## 1. Utwórz repozytorium
Na koncie GitHub wybierz **New repository**, nazwij je `code-rescue-academy` i wybierz **Public**. Nie dodawaj danych uczniów.

## 2. Dodaj pliki
Otwórz repozytorium, wybierz **Add file → Upload files**, a następnie wgraj pliki z tego pakietu do głównego katalogu repozytorium. Zatwierdź **Commit changes**.

**Uwaga:** GitHub może nie pokazać ukrytego pliku `.nojekyll` w niektórych systemowych oknach wyboru plików. Nie jest on niezbędny dla tej aplikacji.

## 3. Włącz GitHub Pages
**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.**

## 4. Sprawdź stronę
Przejdź pod adres `https://TechnikInformatykZSTK.github.io/code-rescue-academy/`, o ile repozytorium utworzono na koncie `TechnikInformatykZSTK`.

Sprawdź:
- nawigację między 34 lekcjami;
- uruchamianie kodu w laboratorium;
- działanie misji i trybu „Napraw kod”;
- mapę kompetencji oraz próbny egzamin;
- zapis postępu po odświeżeniu strony;
- działanie na telefonie i komputerze.

## 5. Zasady bezpiecznego startu
Na początku udostępnij kurs jako materiał do samodzielnej nauki, bez ocen i kont uczniów. Nie wpisuj danych osobowych w ćwiczeniach. Zrób test na dwóch przeglądarkach.

## 6. Aktualizacje
Podmieniaj `index.html` na nowszą wersję. Zostaw bez zmian klucze `localStorage` i identyfikatory lekcji, jeśli zależy Ci na zachowaniu postępów w obrębie tego samego adresu. Zmiana adresu strony lub przeniesienie z pliku lokalnego może spowodować, że wcześniejsze dane nie będą dostępne.
